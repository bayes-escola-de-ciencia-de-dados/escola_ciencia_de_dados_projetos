# 0012 - Contrato como filtro, lente e ficha

- **Data**: 2026-09-28
- **Contexto**: Compradores precisam acompanhar um contrato: consumo, saldo, áreas pagadoras, fornecedor, aportes e esteira expressa
- **Decisão**: Contrato entra no grão do fato (mês x gerência x caminho da subcategoria x diretoria x fornecedor x status x contrato) e vira filtro global e lente; com um único contrato no recorte, a história abre com a Ficha do contrato, uma visão total independente dos filtros
- **Consequências**: Contrato de dados passa para a versão 3.0; indicadores de um só contrato não aparecem sem o contrato selecionado; o grão com contrato acrescentou cerca de 4% de linhas
